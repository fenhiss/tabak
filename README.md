# Neutral Telegram Mini App demo

A small responsive storefront demonstration for ordinary, non-restricted products.

## Run locally
1. Install Node.js 18 or newer.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Deploy
Deploy this repository as a Node web service on a host that supports Node.js.
Use `npm install` as the build/install command and `npm start` as the start command.
The host must provide an HTTPS URL before connecting it to a Telegram bot.

## Important
This is a demonstration: product data is stored in the browser's localStorage.
The admin screen is not secure and is not suitable for real customer data or real sales.
Do not put bot tokens, passwords, or API secrets in the repository.
This demo is intended only for neutral, non-restricted products.
